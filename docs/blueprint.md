# **App Name**: MediScribe AI

## Core Features:

- Real-Time Transcription: Transcribe doctor-patient conversations in real-time using STT (Speech-to-Text) via the OpenAI Whisper tool.
- Medical NLP Extraction: Extract key medical entities (symptoms, medications, history) from the transcripts, using an NLP tool to structure the unstructured data.
- SOAP Note Generation: Generate a structured SOAP (Subjective, Objective, Assessment, Plan) note summarizing the consultation. Uses an LLM as a tool for compiling the information.
- Interactive Transcript Display: Display the real-time transcript with color-coded highlights for recognized medical entities.
- SOAP Note Presentation: Present the generated SOAP note in a clear and organized format, easily reviewable and editable by the doctor.

## Style Guidelines:

- Primary color: Light desaturated blue (#A0C4FF) for a calm and professional feel, suggesting reliability without being sterile.
- Background color: Very light desaturated blue (#F0F8FF) to ensure readability and a gentle contrast.
- Accent color: Soft purple (#BDB2FF), adding a touch of creativity and visual interest without being distracting.
- Body and headline font: 'PT Sans', a modern, humanist sans-serif for clarity and readability.
- Use clear and recognizable icons for different medical entities and note sections.
- Clean and well-structured layout, with the transcript and SOAP note side-by-side for easy comparison.
